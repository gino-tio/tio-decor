## Design H options (`designs/h.html`)

- Views: 效果圖 / 正面 / 門口 / 俯視 / 座廁 / 盆位. 「收埋選項」 collapses the option rows on mobile.
- Toggles: 開鏡櫃, 開廁所門, 全開盆櫃, 座廁蓋, 鏡櫃燈, 尺寸, 施工要點.
- Tap a fixture in 3D (door, mirror cabinet, drawer, vanity door, tap, toilet lid) to open/close it. It presses the matching button.
- 「寫實」 (next to 分享): progressive path tracing with three-gpu-pathtracer 0.0.23 + three-mesh-bvh 0.7.8 (the last versions that work with three 0.165), loaded only when pressed. Mirrors (Reflector) and MeshBasic materials are swapped for PBR ones while it is on. It rebuilds about 1 s after any option changes and stops at 800 samples.
- Drawers (櫃桶): open the top, middle or bottom drawer on its own. 「拆晒櫃桶」 removes all drawers to show the P-trap and the floor-drain access hatch. The drawers are filled with everyday items.
- Toilet: INAX SARAS 100572BW10 / **TOTO CES8E810GCN** (default).
- Narrow ledge on/off. Mirror cabinet bottom 106 / **125** / 130 cm. Mirror doors 3 / **2**.
- Basin: **ceramic ocean basin 8260** / GAODUO stone slab basin (4 colours).
- Cabinet wood: natural / same as door. Hung / **floor-standing on 10 cm stone plinth**. Corner large / small.
- Items: show or hide each buyable item. 「淨睇要買」 shows only the items to buy.
- Pit distance 305 / 355 (INAX only).
- Defaults are set to the chosen spec at load (see the `chosen spec` line near `group('[data-view]'`).

## How to edit and publish

1. Edit `designs/h.html` directly. It is one file: three.js 0.165 from jsDelivr, ES modules, no build step.
2. For a main dimension or the default spec, edit `data/dims.json` first. For the shop drawings, edit `tools/gen_shop.py`, then run `python3 tools/gen_shop.py` (writes `designs/h-shop.html` and `files/dxf/`). Detail sizes inside `h.html` (drawers, mirror-cabinet internals) are still hard-coded there.
3. Commit and push to `main`. GitHub Pages deploys in about 1–2 minutes.
4. To test-render locally: serve the folder, swap the CDN URL to a local `node_modules/three`, then screenshot with Playwright + Chrome (`--use-gl=swiftshader`). The page needs about 20 s to settle with GTAO and bloom on.

Code conventions in `h.html`:
- Units are cm. x is the room width (0 = tub wall, 200 = door wall). z is the depth from the mirror-cabinet wall (0) toward the full-length mirror (148.5). y is up.
- `box()`, `slab()` (extruded plan with an optional rounded front-left corner), `rr()`, `plan()` and `cyl()` are the helpers.
- `makeDrawer(parent,x0,x1,y0,y1,zFront,depth,mat,{by0,bh,uCut,uTo,div,cross,level})` builds a real drawer box. `fillItems()` adds the contents. `carcass()` builds the hollow cabinet.
- `MK('key')` markers put the following objects on a render layer for the item show/hide feature (`LAY` map).
- The user is on a phone. Keep the UI touch-friendly and keep replies short, in Cantonese.
