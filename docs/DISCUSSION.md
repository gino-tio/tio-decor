# 討論紀錄（2026-11-06 至 11-08）

按時間順序，記低每個決定同原因。

## 起點
- 原本：暗水箱＋貼牆座廁（海水沖廁），盆櫃 TOTO 底盆，雲石枱，鏡櫃 120 闊有燈箱。
- Gino 手稿：盆櫃 60×50、離地 90、櫃高 47，左前弧邊、右前直角（門框 1.5），Roca 底盆開孔 490×335，座廁上窄枱 65×10。

## 座廁同供水
- 發現沖廁用海水（灰 UPVC 喉、水箱鏽漬）。一體式智能座廁唔可以用海水。
- Gino 揀方案 B：一體式＋淡水。最初想喺天花將淡水駁入海水喉 → **唔可以**（兩套系統唔准互通，倒流污染食水）。改為：海水喉封頂，由面盆冷水喉開三通＋獨立掣駁 TOTO。
- 坑距推算：暗水箱深 25 ＋ 舊廁去水離廁背 10.5–15.5 ≈ 35.5–40.5 → TOTO 305 或 400 去水件都有可能，拆廁實量先揀。
- TOTO 文件（規格書、安裝說明書 0GH339／D07D72R、CAD）：入水位、遙控位置、後牆 1400 規則；冇開蓋高度 → 由 CAD 推算開蓋頂 ~114，貼近後牆，會撞窄枱同 106 高嘅鏡櫃。
- 試過 INAX SARAS（矮身、開蓋 ~92 唔撞），最後 Gino 揀返 TOTO，配鏡櫃升高。

## 洗手盆同盆櫃
- 方案：Roca 底盆＋石枱 → 陶瓷海洋盆 8260（唔使開石）→ 試過 GAODUO 岩板一體盆 → 最後揀海洋盆。
- 盆櫃：加過雲石托柱（已移除）→ 改為落地＋10cm 石材防水腳（防洗地濕櫃）；地台去水喺櫃底 → 櫃底留維修口（Gino 揀，唔移去水）。
- 圓角：做咗大／細圓角選項，細圓角拉櫃闊啲。
- 拉櫃：按實際存水彎位置做 U 位；可逐格開、放日常用品、可拆晒睇去水。
